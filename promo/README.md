# ChatGPT Bulk Delete promo — light edition

A 20-second 3840 × 2160 Remotion composition with English on-screen copy and an original instrumental score.
The ChatGPT workspace is illustrated using fictional titles and project names.

- Run `npm ci` to install the locked dependencies.
- Run `npm run studio` to preview and edit.
- Run `npm run render` to export `promo.mp4`.
- Run `node score.cjs` to regenerate the included soundtrack.
