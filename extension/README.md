# ChatGPT 对话批量删除 0.0.1

打开 Chrome 的 chrome://extensions 或 Edge 的 edge://extensions。已从输出文件夹安装的用户，点扩展卡片的「重新加载」，再刷新 ChatGPT 网页。首次安装或从其他路径更新时，解压 ZIP，开启开发者模式，点「加载已解压的扩展程序」，选择含 manifest.json 的文件夹。请停用旧版以免出现重复面板。

打开 chatgpt.com 并展开左侧历史列表，点击扩展图标。扩展会自动加载对话。可以停止加载，也可以点击右上角的刷新图标。打开项目的对话列表后，面板会显示网页已加载的项目对话。项目选择框优先显示网页上的项目名称。

扩展会自动获取并保存网页提供的创建日期。默认不限日期，可按早于、晚于或日期范围筛选。早于和晚于不含所选当天，日期范围包含起止当天。日期按浏览器时区计算。

可逐条勾选、拖动手柄连续勾选或全选当前结果。点击「批量删除（N 条）」后核对名单，再点击「确认删除 N 条」。删除无法撤销。

使用「普通聊天」「项目内对话」「整个项目」选择删除对象。切换后会取消此前勾选。打开项目页面可以显示更多项目内对话。删除整个项目时，项目中的对话、指令和仅存于项目的文件也会被删除。
「整个项目」直接读取 ChatGPT 左侧的项目清单，包括侧栏已显示的空项目。「项目内对话」会显示对话所属的项目名称。
